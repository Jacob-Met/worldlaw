    A law earns its keep on motion it has never seen.

    WORLDLAW searches a declared library of scalar angular torque terms. Each challenge uses its recorded command, supplied inertia, initial angle and initial rate; later observed angles are used only for comparison. The default paired runs are synthetic. This test examines predictive transfer within that library; it does not establish a unique physical mechanism.

    Input format and fitting assumptions

    Import a worldlaw.trajectory-bundle/v1 JSON bundle with separate trainingRuns and challengeRuns. The bundle must declare units: {"time":"s","position":"rad","command":"N·m","inertia":"kg·m²","initialRate":"rad/s"}. Each run declares id, label, kind, positive inertia, initialRate, a source object with a label, and ordered samples containing time, unwrapped position, and command. Use distinct runs with strictly increasing timestamps. JSON files must be smaller than 3 MB. Save the example notebook for a complete portable record.

    Angular bundles use worldlaw.angular-bundle/v1 with units: {"time":"s","position":"rad","initialRate":"rad/s"}. Keep each run’s inertia: null, declare dynamics: "unforced_scalar_rotation", and supply initialRate plus source metadata. Samples contain only time and position; no torque command is invented. Training and challenge recordings remain separate.

    Integral fitting compares accumulated displacement; derivative fitting estimates acceleration from the angle samples. Their noise settings have different units and their fit scores are not directly comparable. A good challenge score is evidence for this run, not a probability that a model is true.
