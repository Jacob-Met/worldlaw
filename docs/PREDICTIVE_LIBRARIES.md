# Declared libraries in cross-recording prediction

Trajectory Challenge's **Which law predicts another recording?** apparatus now exposes the angular terms already supported by its maintained selector. The original six terms remain the default. Cubic position and cosine position require explicit offers. The interface lists the actual terms and preserves each complete candidate and training-fold refusal.

The selection algorithm is unchanged: fit each offered structure on the other training recordings, freely predict the omitted training recording, require every fold and numerical screen to complete, select by the aggregate training-validation error, and refit that structure on all training recordings. Only then does the separate challenge assess the frozen model. Viewing challenge outcomes while choosing a library remains exploratory model development.

This connection matters for periodic phase. The weak-equation winner can fit training windows well while predicting another recording poorly. In a fixed exploratory reuse of the existing PASCO bundle, [rate, gravity, bias] gives training-validation RMSE .26087934 rad and separate challenge .22554517 rad. Adding cosine gives .24837227 and .22208471 rad, selecting all four terms. The corresponding pooled weak-fit phase winner omits rate and has challenge RMSE .31870011 rad. These are retained comparisons on reused evidence, not evidence of blind physical improvement or a uniquely identified mechanism. The incumbent full six-term predictive selector remains better on this same reused recording: it selects rate+coulomb+gravity+bias, with training-validation .12932111 rad and separate challenge .08950963 rad. The narrower cosine library is therefore not promoted as a measured improvement over the incumbent. This increment exposes declared hypothesis choices and preserves them on rerun; it does not automatically recommend a narrower family.

The user declares the library; the product does not choose terms from separate challenge errors. Sine/cosine coefficients describe a periodic acceleration component in recorded coordinates, while cubic adds a different restoring hypothesis. Neither authenticates angle calibration, inertia, absolute torque or mechanism identity.

On the independently integrated authored pendulum at phase .237 rad, using two training releases and a separate larger release, the complete original six-term predictive library selects rate+coulomb+gravity+bias with validation .07117602 rad and challenge .35308476 rad. Offering the same six terms plus cosine selects rate+gravity+cosine, with validation4.57864e−8 rad and challenge5.87208e−8 rad. Both use the same four-term cap and complete-work screens. The extended reservation grows from256272 to445104 integration steps and34314 to59598 predicted rows. This is the new supported model-family case; the measured counterexample above remains visible.

## Persistence and refusal

Reopening a custom comparison restores the declared term order and every retained weak-window, rate-estimator, solver, numerical-screen and work-budget option. Rerunning changes only the controls the user explicitly edits. Previously the panel reran with a default library and discarded nonvisible imported declarations; the numeric API already preserved those declarations correctly.

Changing a term invalidates saving until the complete comparison is recomputed. Failed imports or oversized experiments retain the last completed result and its failures, without re-enabling a mismatched save. New surrounding source evidence clears the comparison and resets the library to the ordinary six terms. No source rows are resampled or dropped to fit a budget.

The maintained selector admits at most128 complete offered structures,262144 predicted training rows and2million reserved integration steps. The maximum eight-term library with a four-term cap exceeds the structure limit and refuses; it does not silently prune terms. An empty library also refuses. Users can explicitly choose a smaller hypothesis family, fewer terms or a different independent acquisition. Limits remain part of the actual method rather than hidden execution fallbacks.

`scripts/predictive-library-browser.mjs` exercises the real source import, keyboard library control, training prediction, actual download, custom nondefault notebook rerun, invalidation, work/empty-library refusals, desktop/390px rendering and source replacement. It requires observed Chromium sandbox admission. Numeric selector regression stays in `tests/predictive-selection.test.mjs`; no parallel fitting implementation is introduced.

## Interaction decision

A free-form comma-separated term editor would preserve an arbitrary library but would require users to know internal identifiers and would hide the finite available hypotheses. The chosen labeled checkbox group makes each supported acceleration contribution explicit next to the existing prediction experiment. It retains the actual observed/forecast plot and fold inspection, rather than introducing a new page or a preset that silently changes the model class. Imported ordering remains stable in the stored declaration even though the control order is fixed for readability.
