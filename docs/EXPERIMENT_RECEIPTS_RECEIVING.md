## Retained-history resource experiment

The maintained reproduction is:

```sh
node --expose-gc scripts/experiment-receipt-retention.mjs .
```

It fits a complete eleven-term library with at most seven terms under a broad
declared ambiguity threshold, then retains 128 one-row snapshots of its same
unchanged 1,816-law competitive ensemble: 232,448 model snapshots. It measures
snapshot retention, not 128 full acquisitions, session replay or browser memory.

| Retained snapshot implementation | Heap increase | RSS increase | Capture time |
| --- | ---: | ---: | ---: |
| Initial independent whole-model copies | 269,131,472 bytes | 297,009,152 bytes | 1,563.86 ms |
| Equal-domain sharing and immutable string retention | 143,269,344 bytes | 170,790,912 bytes | 1,135.79 ms |

Both retained every law and every original row. The first receipt's serialized
size remained 1,006,853 UTF-8 bytes. Only exactly equal finite canonical domains
share a frozen copied object within one receipt; the after-fit domain remains
separate and may expand. Exact coefficient and fitting copies stay independent.
The independent regression checks unequal domains, signed zero, source mutation,
frozen shared bounds and changed after-fit ranges.

The heap reduction in this particular probe was about 46.8%. Reusing the same
unchanged ensemble allows immutable strings to be reused across captures, so
this is not a prediction of the savings for 128 changing real fits. The remaining
maximum-history memory is material. Generated-library expansion and browser
peak memory were not qualified by this experiment.
