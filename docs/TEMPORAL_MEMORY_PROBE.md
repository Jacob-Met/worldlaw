# Causal temporal memory probe

The previous two physical interventions closed the periodic omission probes. This experiment is limited to the projected Lorenz temporal omission in Nullgarden 4af7717a866e0246e7c0bcd81977cea53cddbd8c. One related memoryless cubic control will be evaluated under the same acquisition and noise. The global 20-law acceptance, PDE and 60-sham requirements remain separate.

The projected state is position x and velocity v. An unobserved mode can leave exponential history of x² in acceleration. Fit the state-only model v′ = a x + b v + c u + d x³ + e x K + g_j x exp(−λt), with K′ = x² − λK and K(0)=0. Each training recording j has one scalar initial-condition nuisance g_j. Estimate polynomial, control and memory coefficients jointly from weak integrated velocity increments; no derivative, hidden state, true coefficient, future test position or clean calibration outcome enters fitting. Search the 13 preset decay rates 0.25·2^(j/2), j=0…12, using one separate selection recording. Register local cubic and matched transient-only comparators. A negative control drives K with the square of an independently rotated training trace while holding all other inputs and the predictor class fixed. Do not claim the transient or true decay is identifiable because it improves one noisy fit.

Use the original 400-step, 20 ms, 24-substep simulator and original train0/train1/selection/test command profiles. Fit on the two training recordings, choose decay by selection rollout, then score independent test noise draws. Three SNRs 15/25/40 dB, three replicate seeds 73001, 73011 and 73021 with fixed train/selection/test offsets 0/1/2/3. Use only the first 11 observations to initialize the prefix nuisance in selection and test forecasts. Run 390 open-loop predictions. Primary error is the full relative state error with divergence penalty 10. Retain first 50 steps as a distinct short-horizon diagnostic. Compare all nine paired rows; no post-outcome changes to profiles, thresholds, models or seeds. The mechanism-specific test requires winning against local, transient-only and wrong-history comparators on mean full error and on at least seven of nine held recordings. A passing mechanism probe alone cannot admit any broad discovery result.

The algebraic source check is independent of the data-driven fit. In the original projected system, setting h=z−x²/20 gives h′=(13/15)x²−(8/3)h and v′=270x−x³/2−11v+u−10xh. This identity does not require division by x, so it remains defined at zero crossings. The data-driven model does not receive these values. It must distinguish the causal memory from an arbitrary decaying initial-state correction.
