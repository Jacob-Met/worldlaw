# Repeated-state diagnosis

Discovery Studio now decomposes the inspected model's training residuals directly beneath its residual chart. Exact command, position and rate triples define groups; nearby states are never silently rounded together. Every training row contributes, including singleton groups.

For each group with mean observed torque m and fixed model prediction f, the identity is sum(y-f)^2 = sum(y-m)^2 + n(m-f)^2. The first term reports within-state scatter; the second reports weighted group-mean mismatch. The displayed scatter divides by N minus the number of unique states before taking a square root; mean mismatch divides by N. The module also retains both sums, all denominators, per-state contributions and numerical decomposition error. No replication yields an unavailable scatter, not zero uncertainty.

This is a descriptive decomposition, not an F-test or a calibrated confidence interval. Group means contain sample noise; the model may have been fit and selected using these same observations. No automatic coefficient-count correction or significance decision is made. A single repeated state does not identify a law. Identical copied rows can produce zero scatter without establishing repeatability. Independence, matching true physical state, stationary apparatus and source authenticity are not established by exact declared coordinates. Drift or hidden state can contribute to within-state variation.

The module reuses the maintained evaluate function and its validation/work bounds. Model inspection updates the diagnosis. Existing notebook inputs reproduce the view without persisting derived statistical claims. Held-out rows are excluded and fitting, ranking, acquisition and existing science remain unchanged.
