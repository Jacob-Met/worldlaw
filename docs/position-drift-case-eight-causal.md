# Seven pulses are necessary and sufficient for historical case 8

A [seven-pulse fixed tape](persistent-position-drift-multiclass-minimum.md) identifies all four laws. A single online strategy now rules out every six-pulse feedback policy at the original error bound of one. It can reply before the experimenter chooses the next command.

The initial reading is zero. For each of the first five commands the reply increments by the mean of the L0 and L1 rates for that command. These laws remain jointly feasible throughout: their binary minimum is six, and their causal midpoint admits two physical starting states at every shorter horizon. Usually the adversary can extend this same trajectory once more. The two exceptions among the 729 ordered six-command words are u0,u0,u0,u1,u1,u1 and its reversal.

On either exceptional word L1 remains feasible after five commands. L1 and L2 differ by the constant 2 on u0 and u1, the only commands in the word. Any persistent L1 position/drift state compatible with the preceding readings thus has an L2 counterpart with its drift shifted by 2. After the sixth command is revealed, select a last reading in the two laws' joint closed interval. The earlier replies stay exactly as emitted. For every feedback policy, following these replies determines one of the covered paths. A single initial state for each surviving law reproduces every observed position on that path to within one. This is a lower bound against sure identification.

The implementation derives each possible last-reading interval by intersecting the constraints from the new tick and each pair of old ticks. A previously feasible history contributes closed strips on initial position and drift. Planar Helly implies the intersection with the new strip is nonempty exactly when each indicated triple intersects. The resulting interval includes endpoints. The same persistent-state receiver independently reconstructs the starting states once the last reading is fixed.

Run `node --test tests/position-drift-case-eight-causal.test.mjs` to replay all 729 terminal words and all 1,093 distinct prefixes. The test independently forward-simulates the returned initial states using the original integer rates and exact rational cross-products. The six-pulse strategy changes its last reply only on the two exceptional words.
