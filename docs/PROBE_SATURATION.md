# Declared saturated-rate response revision

UNKNOWN LAB's existing cross-probe instrument can now explicitly compare a bounded smooth rate-saturation family alongside its original four hypotheses. The investigator declares one to three positive velocity scales; each new law has the form contrast = a tanh(rate / scale), with the same one unknown coefficient a constrained by every original training screen. Scales are stated in rad/s and coefficients in N m. This is a finite declared library, not friction-mechanism identification, an inferred physical time constant, continuous scale fitting, or calibrated uncertainty.

## Actual consumer

In the existing cross-probe panel, choose the authored saturated-rate control or import a study. Open Revise with declared saturated-rate alternatives, enter one to three comma-separated scales and explicitly compare them. The original constant/rate/sine/no-change results remain visible, including their failures. The original four-hypothesis option removes the declared expansion without changing any measurements. Individual and two-state acquisition comparisons consume the same declared features and coefficient intervals. The mixed-response instrument retains its separately declared affine library.

The schema worldlaw.probe-response/v2 requires rateSaturationScales; original v1 remains unchanged and rejects saturation declarations. Old clients therefore refuse the new input rather than silently reinterpret it. Export/reopen preserves the actual evidence and declaration; predictions are recomputed. The training API still rejects challenge-bearing inputs. Changing separate challenge values cannot change fitted coefficients or declared scale selection, although choosing a grid after viewing challenges is exploratory reuse, not blind validation.

## Executed synthetic result

An authored control replaces the original paired drag contrast with -0.4 tanh(rate/0.2), retaining its independent drift and deterministic perturbations. All original four hypotheses are incompatible. Of declared scales 0.1, 0.2 and 0.4 rad/s, only 0.2 remains compatible, with coefficient interval approximately [-0.4022003665, -0.3976471572] N m. The same frozen interval is compatible with all three separately retained synthetic challenge runs. A 0.28-rad/s off-grid response rejects the whole declared grid; challenge corruption remains an explicit contradiction. These are authored numerical controls, not physical measurements or a general model-discovery claim.
