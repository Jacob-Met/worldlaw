# Joint mixed-response consistency

This successor to the exploratory mixture comparison asks a different question:
is there one coefficient vector, inside the explicit −100 to 100 domain, whose
response lies inside every included original probe screen? It reuses the
maintained bounded linear-envelope search and independent witness/separator
checkers. It does not introduce another optimizer or replace the point fits.

## Two distinct questions

**Training only** excludes challenge values from the coefficient search.
**All evidence** includes both roles and is explicitly retrospective family
consistency. An all-evidence witness is never a frozen prediction: every included
measurement constrains it. Neither mode changes the maintained planner or the
original single-term interval comparison. A training-only certificate pins the
complete original study for custody, even though challenge values do not affect
its coefficient search.

The input wrapper records the original normalized probe study, offered mixed
family, role scope and both work budgets. Each certificate binds that entire
question. Public checking reconstructs the envelope from original source inputs,
rejects altered source/family/scope, and independently evaluates witness
coefficients at the original coordinates. Dense finite vectors, dimensions and
coefficient/weight bounds are admitted explicitly. Saved requests contain inputs
only; reopening recomputes conclusions.

## Numerical meaning

For the included source contrast vector y and feature rows A, the computed
coefficient family is |c_j| ≤ 100, with |(Ac)_i − y_i| ≤ r_i. The r_i are the
maintained heuristic counterbalanced observation screens, not calibrated
confidence intervals. Missing acquisition-order qualification prevents this
analysis.

An interior witness must independently satisfy every original screen with a
positive numerical margin. A separating vector v is checked using

    v·y > 100 ||Aᵀv||₁ + Σ_i r_i |v_i| + numerical tolerance.

The support expression covers the entire offered coefficient box; the source
checker retains the weights, projected coefficients, supports and positive gap.
These are engineering arithmetic screens, not exact interval certification of
floating-point features, formal proof of physical impossibility, or identification
of a physical mechanism. Boundary contact and exhausted work remain unresolved.
A rank-deficient design may still admit a coefficient witness; it does not
identify unique coefficients.

## Experience choice

Two compositions were considered: a coefficient-space plot and a source-screen
witness inspection. The implemented inspection associates each actual source
run with the same coefficient vector, or with its weight in the separating
inequality. This matches the computed evidence: the bounded search returns a
witness or separating certificate, not a complete geometric feasible region.

surrounding experience. A selected witness is explicitly an explanatory
consistency example, never an observed mechanism animation.
