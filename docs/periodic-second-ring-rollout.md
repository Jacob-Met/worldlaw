# Propagating the measured second spatial ring

The finite operator receiver accepts measured left2 and right2 values. A full simulated periodic field contains these values by wrapped indexing at j−2 and j+2. On the eight-cell wave [1,0,−1,0,1,0,−1,0] at spacing 1/4, the local operator −0.001 × biharmonic(field) returns −1.024 at cell zero. The public rollout previously threw “Second spatial neighbors required” on the same full state. The shared row constructor supplies the actual cells in explicit integration, model admission and stage evaluations. Sparse acquisition rows still require the measured second-ring inputs.

Let θ=2πk/n, G=i sin(θ)/h and A=−4sin²(θ/2)/h². The literal third-difference stencil has multiplier GA and the fourth-difference stencil has multiplier A². The interval transition combines these with the original advection and diffusion terms. The third derivative has zero frequency response at the Nyquist mode. At all other tested frequencies, reversing its sign changes the direction of propagation. The affine compiler also accepts a constant plus a multiple of the field inside either spatial derivative.

For nonlinear forces, the periodic integrating-factor stage retains a spatially constant signed linear combination of the recognized stencils. Its mixing-time budget uses the largest actual mode rate computed from the finite ring. Direct physical evaluations retain the neighboring potential values and the command at the stage time. Computational budgets and trajectory-refinement checks apply on each course.

The source test covers all 13 positive wave numbers across 7-, 8- and 13-cell rings using the literal signed five-point symbol. It also checks 12 authored fourth-order systems. Each combines negative linear diffusion, stabilizing fourth-order diffusion, a Laplacian of the cubic field potential and a chirped actuator. Against direct physical-stencil midpoint integration, the largest saved-state error is 2.64e−9. The largest coarse/fine prediction difference is 9.14e−9 and doubling the independent reference resolution changes a saved state by at most 1.57e−9. A changed terminal reading of 0.001 fails every trajectory gate. These are numerical propagation tests for specified operators and full fields. Inference from noisy states belongs to the separately registered acquisition.
