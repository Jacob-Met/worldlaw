## Locked source roles and leakage boundary

For each 4T mode **independently**:
- Source original Training workbook: chronological first 70% **fit only**, last 30% **development only**, no reordering by output value. If actual source has finite-value/timestamp dropouts, split at discontinuities, never fill or bridge; retain exact segment IDs/counts, and use at least 128 valid consecutive rows per usable segment. The source 4T-M1/M2 original Test workbooks are NEVER loaded in fitting process.
- Develop independently selected M1 and M2 parameter families from each ORIGINAL training file only. All registered model types, orders, ridges, learned coefficients, valid-channel scalings, original source/model SHA must be frozen on disk before another process opens ANY original Test workbook.
- Independently receive original M1 Test and M2 Test workbooks. Each valid source-contiguous test segment permits **first 64 actual four-tank sensor samples** only for forecasting initialization. Then predict all remaining test tank levels **autoregressively** using the source-recorded future pump commands, never future sensor values. The original two test files are fully separate from training source files.
- Evaluate four original source scenarios: M1-fitted -> M1 original Test, M2-fitted -> M2 original Test (**within-condition tests**); M1-fitted -> M2 original Test and M2-fitted -> M1 original Test (**cross-configuration transfer**, no source-specific refit or receiver calibration beyond first64 actual source sensor observations). No 2T/3T source rows or labeled fault source rows may silently replace or augment 4T fit/receiving.
- For any target mode, compute physical units/normalization **only from the target MODE original training sensors** (stored before test), independent of test values; no source sample from a Test workbook tunes or selects a hyperparameter or physical topology.

## Locked candidate families and search

All use all **four** observed tank states, both pump commands, causal input lags, and the same prefix/pump future trajectory; no test target lookahead.

1. No-fit last-observed-state persistence.
2. True **4-output, fully cross-coupled linear ARX** levels+both pump channels, orders **2,4,8,16**, ridge **1e-6,1e-4,1e-2,1e-1**; fit 4 outputs together, select each original-mode candidate by development full-horizon macro score.
3. Strong **quadratic multivariate NARX**, orders **2,4** with the same 4 ridge strengths; includes all linear causal lagged four tank sensors and two pumps, plus immediate-state levels squared, pumps squared and all tank×tank, tank×pump interactions; original development-only selection. A strong data-driven comparator is selected as the **better DEV score of independently chosen ARX or NARX**, strictly before any original test access.
4. Physically signed four-state square-root flow with pump 1 feeding tank1/tank4, pump 2 feeding tank2/tank3, upper tank3 draining into lower tank1, upper tank4 draining into lower tank2 (published quadruple-tank archetype), and nonnegative own-tank drainage; coefficients estimated by original training-only ten-original-sample smoothed derivative windows with nonnegative directional flow/pump constraints and unconstrained sensor offset. A predeclared **no-crossflow ablation** removes upper-to-lower transfer features. Both are fitted with ridges **1e-8,1e-5,1e-3**, and all six training attempts plus rejected cases survive in the frozen artifact. Actual plumbing/valve split may vary between M1/M2; fitted pseudo-sensor coefficients are not direct SI flow measurements.

Development always scores identical **full-autonomous 64-sample-initialized forecast**, not free teacher-forced one-step fitting error. If all registered candidates numerically refuse, report the family as unsupported and retain exact failures; don't secretly invent a rescue family.

## Primary score, negative controls and promotion

Let target original training channel standard deviation be s_i. For each of four original tank channels i, s_i is floor-clamped to max(1e-6, 0.05 × original target training range). Score each original Test recording's **entire recursively predicted remaining samples** as RMSE_i in original author sensor units and NRMSE_i = RMSE_i/s_i. Primary macro is the arithmetic mean over all four sensor NRMSE values; report source file/session counts, individual per-tank RMSE, per-timepoint error and 1/30/120-sample fixed-start windows. Never interpret temporally correlated test timepoints as independent scientific replicates.

Original source test negatives (predeclared): shift both pump input sequences by **+97** recorded rows, force both pumps zero, swap only tank1 and tank2 predicted output identities at scoring, and fit original training-only sham with target sensors circularly shifted by **+37** rows (using the selected ARX order/ridge but no extra test-driven selection). Compute their original test scores without changing frozen candidates. If a physically signed model is unaffected by pump timing or zero pump, record loss of demonstrated physical control response, not a positive causal law.

Promote the physical explanation ONLY if ALL hold: both M1 and M2 original within-configuration Test macro NRMSE are **≥10% better** than their own **development-selected strongest ARX-or-quadratic-NARX** baseline; each no-refit M1->M2 and M2->M1 original cross-configuration macro error is **≤1.5 ×** the corresponding same-source-fitted strong data-driven baseline transferred to that SAME target; and both actual pump perturbation negatives worsen in both original within-config tests. Otherwise the strongest honest result is an explicitly failed original transfer criterion with full source-level failure boundaries. No isolated one-step or teacher-forced result can replace the prospective primary.

## What this source cannot establish

Original sensors may provide native calibrated levels or raw voltage, to be determined strictly from source documentation; don't assign SI flow/height units without primary calibration. Actual mode M1/M2 may alter valve topology or pump gain, making frozen cross-mode transfer physically nonidentifiable; report this failure rather than declaring a new physical law or retraining on Test. Source has **one physical quadruple-tank apparatus** and two separate operational modes, not independent hardware builds. The decisive next test after consuming the two official Test workbooks requires an independent apparatus and safe randomized actuator perturbations. The original sensor fault detection files are a distinct possible future task, not admissible model-selection examples here.
