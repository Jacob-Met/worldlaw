# Supplied-reading curvature witnesses

For three distinct, monotone observed angles inside one original directed smooth segment, let h1 and h2 be the positive adjacent angular distances and H their sum. The cross-multiplied contrast is C = H*y1 - h2*y0 - h1*y2. Independent torque-radius boxes give radius R = H*r1 + h2*r0 + h1*r2. A declared second-derivative magnitude M implies |C| <= B = M*H*h1*h2/2 for exact torques.

The workbench rejects this necessary condition only when max(0, |C|-R) > B. Equality is compatible. Binary64 input values are converted to exact dyadic integers and powers of two before subtraction, multiplication and comparison. Large common offsets, subnormal spacing and cancellation therefore do not create a rounded false contradiction. Display values are approximate; exported exact arithmetic values are explanatory derived output.

Witnesses use consecutive available triples within each original directed segment, retaining original-row and acquired-reading identities. They never cross a zero-angle torque jump or a branch boundary. Missing readings remain pending. No interpolated torque becomes evidence.

A contradiction withholds the conditional continuous-path result, including its coarse interpretation. Original polygon work remains available; complete receiving also retains refined polygon work and the original noncurvature allowance. Compatibility is only a necessary check of the inspected triples. It does not establish existence of a jointly compatible smooth function, authenticate the curvature assumption, validate exact angles or verify acquisition provenance.

The false-curvature control declares M=1 for an authored theta-squared response. Its actual supplied analytic readings contradict that declaration; sufficiently broad declared torque boxes can make the necessary check compatible. Authored controls explicitly include a floating-evaluation radius. Previously saved inputs retain their original declared radii.
