# Append an actual instrument reading file

The existing experiment card accepts a later actual-reading file without replacing its starting notebook. Select a CSV or dedicated measurement JSON, inspect the original source label and complete row count, then explicitly append. Before that action no observations or fit are changed. The maintained appendMeasurements path creates one pre-refit receipt for the full batch and then refits; undo removes the whole event. Source-only notebook export retains every admitted value, source label and declared units.

CSV headers are command,position,rate,jointTorque, with optional torqueNoiseRatio. Standard units are command and jointTorque in N·m, position in radians and rate in radians/second. CSV file names supply the acquisition source label; this does not authenticate an instrument or independence. JSON must use worldlaw.measurement-batch/v1 with source:{label,units} and rows; units must declare those same canonical values, plus torqueNoiseRatio:'1' when present. Extra response-derived fields and observation/held-out notebooks refuse instead of silently becoming measurements.

The intake admits1–4096actual rows subject to the notebook's complete4096row and existing event/work limits, and a2MB UTF-8 file limit. It preserves complete per-reading noise-ratio declarations; mixed cohorts refuse. Virtual notebooks require importing a real observation notebook first; no predicted value is converted into an observation. Subsequent actual files do not redefine offered inputs, the original calibration source or held-aside evidence.

Every new file/source generation retires an earlier pending read. A preview is tied to its accepted notebook generation, and explicit append checks that binding again. Actual manual acquisition, refit, undo or source replacement clears the preview. A failed file leaves accepted scientific source unchanged. Re-importing an identical file is an explicit new acquisition, not silently deduplicated: repeated measurements can be intentional; the operator remains responsible for provenance.

This separate acquisition path appends it to8original rows, retains an8row prior prefix and2row pre-refit receipt, then reopens all10rows from original source. It adds no parser/fitter substitute: CSV tokenization and observation admission reuse maintained primitives, as does normal acquisition/refit/replay.
