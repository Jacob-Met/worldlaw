    IMPORTANT / NOT A VERDICT OF PHYSICAL TRUTH

    This bounded screen tests a deterministic current-state-only description under a declared torque noise assumption. Counterbalancing removes only a linear per-reading order term; it does not validate instrument stability, independence, timing or absence of nonlinear drift. A result can challenge that description but cannot distinguish latent physical memory from changing instruments, other unobserved conditions, preparation artifacts or systematic measurement drift. An inconclusive result does not confirm memorylessness. Imported evidence is user-declared, not authenticated.
