# Can one position-only response fit every original reading?

This Coupling Lab inspector receives the original ordered point-reading boxes from the maintained circulation consumer. It complements integrated work and fixed affine model comparisons. It does not refit a response family, inspect shared training perturbations, or infer a history effect.

For each torque output a, the caller explicitly supplies nonnegative sensitivity limits L[a,b] in N·m/rad for both exact input coordinates. These define a weighted coordinate distance d_a(q,p)=Σ_b L[a,b]|q_b−p_b|. Zero limits are admitted; the resulting pseudometric requires equal responses along its zero-distance directions. Limits are declared hypotheses with retained source/basis text, never inferred from the same outcomes. Default ones are clearly labeled illustrations.

Every original reading supplies [lower_i,a,upper_i,a]. Compatibility is equivalent to lower_i,a−upper_j,a≤d_a(q_i,q_j) for all ordered pairs and both outputs. Necessity follows immediately from any response lying inside the boxes and satisfying the sensitivity bound. Sufficiency is constructive: f_a(q)=max_i(lower_i,a−d_a(q,q_i)). Each term obeys that output's sensitivity bound, as does their finite maximum; its own source term ensures f_a(q_j)≥lower_j,a, and all ordered-pair inequalities ensure f_a(q_j)≤upper_j,a. Independent output constructions form a vector response, without any potential or reciprocity assumption.

The implementation reuses maintained binary64-to-dyadic conversion, addition, multiplication and comparison. Exact finite source values and reading radii are not screened with a tolerance. It returns a positive exact gap and original pair when incompatible, or the formula and exact source-node witness values when compatible. A complete128-row cap bounds work to32768 ordered output/pair checks; larger sources refuse without trimming. Source query evaluation recomputes from inputs rather than trusting a saved certificate.

Repeated-coordinate contradictions require no finite slope restriction: the allowed state-response change is zero. Other contradictions are conditional on the explicit sensitivity hypothesis. They do not identify the physical cause. Omitted rate/state/history, drift, calibration errors or wrong bounds remain possible explanations. Compatibility only establishes an available mathematical response through the original point boxes. It does not reproduce the declared piecewise-linear torque interpolation between readings, fit physical behavior, prove a conservative potential, establish passivity, or identify a mechanism globally.
