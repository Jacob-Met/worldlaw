# Configured Fast-SC window

The first native comparison used a 256-point Hann window. GNU Octave 8.4.0 running the released Fast_SC.m and the Python implementation agreed across all 186,534 complex values in that fixture. The physical protocol uses a 512-point window. Physical admission is on hold for a separate native comparison at that size.

Fast_SC.m uses the first window maximum to set the complex phase correction and to construct the calibration weights. GNU Octave 8.4.0 hanning.m computes the symmetric window from cosines sampled from zero to two pi. SciPy 1.18.1 implements the general cosine window with angles sampled from minus pi to pi. At even window lengths, tiny rounding differences between the two central samples can change the selected index.

In a source-only check with NumPy 2.3.5, SciPy 1.17.0 and a scalar libm evaluation of the Octave expression, both formulas chose zero-based 127 for a 256-point window. At length 512 SciPy chose 256 and the scalar expression chose 255. Two artificial signals through the same Python receiver exposed the impact. Across the registered common positive grid, the worst cell was 7,375 Hz, order 1/64, in both cases. At 64 frames it changed from 0.0011713332453 to 0.0011835016334 and at 65 frames from 0.0011711253600 to 0.0011832914515. The maximum differences were 1.02817% and 1.02816% of the corresponding alternative's peak. Source inputs were deterministic amplitude-modulated tones plus an impulse train. These figures describe the local diagnostic only.

The prospective native fixture binds the released Fast_SC.m by SHA-256, a signed-package GNU Octave 8.4.0 runtime, NumPy 2.5.5 and SciPy 1.18.1. It exercises 5,111 and 5,112 frames at 64 kHz with the 512-point window, 50-sample hop and 640 Hz cutoff. The receiver compares every complex value, the complete 257 by 1,281 registered magnitude grid, and all 324,478 common positive cells. It records both native central window values, the first maximum, the complete window bytes, the raw worst values and a separate reference using the literal native coefficients. Qualification requires peak-scaled error below 1e-10 in the full complex matrix and the full registered grid for both record lengths.

The original native execution request was refused before provider dispatch because the gateway had 2,110,668,800 bytes free against its 2,147,483,648-byte reserve. No native W512 result or physical measurement has been observed. This request and the earlier W256 receipt have separate identities.
