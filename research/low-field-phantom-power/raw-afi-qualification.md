# Source qualification of the 0.55 T Keenan phantom

## Registered question and disposition

The proposed estimator required two reconstructed actual-flip-angle imaging (AFI) intensities plus variable-flip-angle (VFA) images on the same run. The author release supplies a filtered B1 map in each phantom VFA file. None of the 12 retains the two AFI intensity images. No registered fit, reference-based estimate or performance result was produced.

The 57-entry v2 inventory contains 12 VFA and eight IRSE phantom objects across four explicitly labeled scanner folders, two excluded human objects, one README, 32 other folder-assigned phantom T2 objects, and two unassigned T2 objects with exact folder-assigned duplicates by length and MD5. The 20 T1 source files were authenticated individually. Their MAT containers were read as bytes and structural metadata. A separate restricted decoder interpreted only the stored sequence parameter tables. No image/map amplitudes, mask membership, fitted values or individual vial NMR reference values were read. The public article's aggregate ranges and published outlier discussion are already known.

All 12 VFA volumes have seven contrasts and a single interpolated B1 map. Eleven archived parameter tables are four-row high-angle fits. The exception, Prototype_1 MID574, fitted all seven. A source reconstruction calls qMRLab on the last requested contrasts. For a strict four-to-three omitted-contrast forecast, that run's seven-angle fitted values would contain held information. Each IRSE file has seven inversion times (50,100,200,400,800,1600,4500 ms) at TR 5 s. There are two single-slice IRSE files per scanner and three repeat VFA files per scanner, so the standard protocol is not a distinct matched acquisition for every short-protocol repeat. The paper's 20 °C NMR reference is from 18 separately measured same-batch witness samples, nine of each salt. It is not a fresh reference measurement for every scanner or every vial.

## Acquisition and information loss

The source AFI program alternates first and second RF excitations separated by a nominal 32 ms, with the second followed by a nominal 96 ms before the next pair. RF/ADC spoiling increment is 39° for AFI and 169° for VFA. The AFI kernel plays two extra spoiler/gradient kernels without RF. These source choices do not establish perfect spoiling on each scanner. Direct timing of the published compiled AFI file found 3,784 excitations, 3,584 ADC events and short/long RF-onset gaps of 32.01–32.27 / 96.03–96.81 ms. The VFA program has 50,876 excitations, 50,176 ADC events and 23.00–23.53 ms RF gaps. Nominal product headers say 32/96 and 23 ms. The released MAT files do not bind every run to a scanner-executed copy of a specific compiled file.

The qMRLab submodule 036ff20b47e939877f746940a969494b55911636 computes the angle from the absolute second/first signal ratio. Ratios above one map to zero raw angle and field values below 0.6 are set to 0.6 prior to spatial filtering. The VFA receiver resamples the filtered field by a factor of two. Positive pairs (100,101) and (100,105) map to the same floored field despite different intensity ratios. Even in the valid unclipped region, (100,75) and (200,150) give identical ratios and different raw intensity amplitudes. Multiplying both images by a receive gain cancels in an ideal ratio, but the released map cannot provide the pair, amplitude-dependent noise likelihood, discarded values or original independent spatial samples.

A design-only test uses a noiseless, perfectly spoiled forward model with nominal TR. It sweeps 420 T1/physical-field points. Given the biased apparent field from the finite-TR AFI model, refitting T1 and scale on the four higher flip angles yields a median maximum low-angle relative difference of 0.00735% and a worst of 0.06775%. The worst parameter case shifts 25 ms to 57.53 ms while the true and apparent fields are 1.30 and 0.8555. These are finite-grid sensitivity results for the stated ideal model, not scanner measurements, bounds outside the grid, or performance of an algorithm on the public vials.
