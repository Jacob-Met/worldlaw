# Authored interval-averaging measurement receiving (#438)

This isolated experiment keeps a fixed executable harmonic law and an independently supplied point initial state. The source is an explicitly authored ideal scalar angle-averaging sensor. It is not a camera model or a PASCO explanation. No real exposure metadata is admitted.

The protocol was written before run.mjs was first executed. Its unchanged bytes are hashed in results.json. Original observations are analytic integrals over explicitly declared 1/16-second windows; timestamps are declared as either interval center or end. The 61 windows and all readings are retained in results.json. No fit or source correction is performed. Later placeholder positions in the solver query grid are clearly labeled as numerical query scaffolding, not measurements; only the independent point initial state initializes the forecast. The experiment ignores those placeholder residual metrics.

The maintained solver generates point predictions. A separate research-only operator uses composite trapezoids on exact existing prediction nodes to approximate interval averages. It refuses missing endpoints, unsupported timestamp semantics and excess complete-population work before averaging. These prediction nodes are numerical evaluations, not additional observations. Overlapping windows reuse predictions and are not independent evidence.

At 4,096 grid intervals, point forecast RMSE against the authored averages is 0.0690780860144594 rad for centered stamps and 0.5270868730125147 rad for end stamps. Applying the declared measurement operation to the unchanged forecast reduces both to 0.0000019574483360678284 rad. The maximum point prediction error against independent cosine truth is 2.786360239759311e-10 rad. The much larger remaining average error is primarily observation quadrature error. Across 256, 1,024 and 4,096 grid intervals, its RMSE is 0.000501738616334119, 0.00003131997465731387 and 0.0000019574483360678284 rad, consistent with second-order quadrature here. These comparisons are not certified error bounds or universal convergence claims.

The result changes the interpretation of point residuals: these readings can disagree with point predictions while agreeing with the unchanged dynamics passed through the explicitly declared readout operation. This does not identify a physical law, prove that any real sensor integrates this way, or license inferring exposure from cadence. Averaging image intensity/marker coordinates and then deriving angle is generally a different nonlinear operation.
