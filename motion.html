TAKE THE EVIDENCE FORWARD

From motion to a model.

Export measured angles from a continuous segment with source provenance. Save the notebook to retain the full ledger and its gaps. The torque studio additionally needs known inertia and an explicitly declared command.

Derive observations for the torque studio

A fixed pivot and a planar rigid rotation are assumptions you supply. Numerical differentiation amplifies pixel noise; derived torque is an estimate. Command is never inferred from video.

Import the exported JSON using “Import observations” in the torque studio. Short or broken segments cannot support derivative estimates.

∴

The pixels are evidence. The mechanism is still a hypothesis.

This instrument measures one textured marker around a user-declared fixed pivot in a stationary, approximately front-facing view. It does not recover depth, moving pivots, unknown topology, inertia, or applied forces. Correlation scores describe a pixel match, not a calibrated probability. Synthetic examples are rendered test inputs; local recordings retain their own source identity.
